# 🖥️ Retro Hardware

Aplicativo Android desenvolvido para a atividade de desenvolvimento mobile, com o tema **História do Hardware na Computação**.

## 📚 Sobre o projeto

O Retro Hardware é um catálogo interativo que apresenta componentes e tecnologias que marcaram a evolução da computação.

O aplicativo aborda elementos históricos como:

- Válvulas eletrônicas;
- Cartões perfurados;
- ENIAC;
- Primeiros microchips.

A proposta é permitir que o usuário explore cada item por meio de cards e visualize informações detalhadas sobre sua importância para a história da computação.

## 🎯 Objetivo

O objetivo do aplicativo é apresentar, de maneira simples e interativa, algumas das principais tecnologias responsáveis pela evolução do hardware e dos computadores.

## 🛠️ Tecnologias utilizadas

- Kotlin
- Jetpack Compose
- Material 3
- Firebase Authentication
- Cloud Firestore
- Android Studio

## 🔐 Autenticação

O aplicativo utiliza o **Firebase Authentication** para realizar o cadastro, login e logout dos usuários.

A autenticação é realizada através de:

- E-mail
- Senha

## ☁️ Backend

O **Cloud Firestore** é utilizado como backend para armazenar os dados dos itens apresentados no catálogo.

Cada documento contém informações relacionadas ao componente ou tecnologia, como:

- Nome
- Ano
- Categoria
- Descrição
- Importância histórica
- Componentes relacionados

## 📱 Funcionalidades

- Cadastro de usuário;
- Login com e-mail e senha;
- Logout;
- Catálogo de hardware histórico;
- Cards clicáveis;
- Tela de detalhes;
- Integração com Cloud Firestore;
- Identidade visual própria.

## 🏛️ Temas apresentados

### Válvulas eletrônicas

Tecnologia fundamental nos primeiros computadores eletrônicos, utilizada para controlar e amplificar sinais elétricos.

### Cartões perfurados

Um dos primeiros meios utilizados para armazenar e fornecer instruções e dados para máquinas de processamento.

### ENIAC

Um dos primeiros computadores eletrônicos de propósito geral, desenvolvido durante a década de 1940.

### Primeiros microchips

Os circuitos integrados representaram uma grande evolução na miniaturização dos componentes eletrônicos e contribuíram para o desenvolvimento dos computadores modernos.
